# SOM Engineering Calculator V11

Student-focused Strength of Materials + Civil Engineering calculator suite.

### V11 updates
- Beam types: Simply Supported, Cantilever and Fixed Beam.
- Beam loads: Point Load, Full UDL, UVL and Applied End Moment.
- Beam result includes SFD/BMD, formula and a **Step-by-step Explanation** option.
- Material Properties expanded with E, Poisson ratio, G, K, density, yield strength and ultimate strength.
- Formula Reference expanded with additional SOM formulas for deformation, bending, shear, torsion, beams, columns and strain energy.
- Survey and all calculation-result PDF buttons fixed using a print-target workflow.
- L × B area now accepts ft, m, in, cm and mm.
- Steel/Rebar now supports solid round, hollow round and hollow rectangular sections.
- Every major calculator screen starts with a short definition explaining what the tool does.
- Service-worker cache version updated for V11.

All quantity/cost/structural results are educational or preliminary estimates and must be verified against applicable codes, drawings, specifications and local rates before real-world use.
